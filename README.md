# IntelliHRM

## Project overview

This repository contains an HRMS Lean V1 application inside the `HRMS-New/` directory. The product covers employee records, departments, attendance, leave balances and requests, payroll, authentication, and role-based dashboards.

## What it contains

- React frontend
- Express backend API
- Prisma ORM with PostgreSQL
- JWT-based authentication
- Documentation, tests, and an E2E workspace
- Docker Compose and workspace package configuration inside `HRMS-New/`

## Current status

The repository is one of three closely related HRMS repositories in this GitHub account. The complete application is nested one level below the repository root, and its relationship to `HRMS-NEW` and `IntelliHRMS` has not yet been formally recorded.
